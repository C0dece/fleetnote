# Fleetnote — заметки для ИИ-агента

Проект разрабатывается по `SPEC.md` (ТЗ, дизайн-система, план по 5 фазам).
Текущее состояние фаз и список доработок — в `README.md`.

## Договорённости

- Язык интерфейса и комментариев — русский; код, имена файлов и переменных — английский.
- Строгая типизация: `npm run typecheck` должен проходить без ошибок.
- Форматирование: `npm run format` (Prettier, printWidth 110).
- Тесты ядра: `npm test` (Vitest). Покрыты слияние, разбор Markdown, пути,
  свойства заметки и сквозные сценарии синхронизации с подставным хранилищем;
  новую логику ядра добавлять с тестами.
- Любая работа с файлами идёт через `VaultFs` (`src/core/fs`), а не через плагины Tauri напрямую:
  это даёт браузерный демо-режим и упрощает мобильную сборку.
- Облака подключаются только через `IStorageAdapter` (`src/core/sync/types.ts`).
- Пути внутри базы — относительные POSIX (`Daily/2026-10-21.md`), без системных путей ОС.
- Компоненты общие для ПК и мобильных; расходится только обвязка навигации
  (`AdaptiveShell` → `DesktopShell` / `MobileShell`).
- Рабочая область — дерево раскладки (`src/core/layout.ts`): панели и сплиты.
  Вкладки живут в панелях (`editorStore.panes`), перетаскивание — через `dragStore`.
- Всё настраиваемое складывается в `settingsStore`; оформление превращается в
  CSS-переменные только в `src/core/theme.ts`, компоненты читают переменные.
- Специальные вкладки (граф, холст) опознаются в `src/core/views.ts` и рисуются
  в `PaneView`, а не в `EditorPane`.
- Блочные декорации CodeMirror задаются только через `StateField` — из ViewPlugin
  редактор их не принимает и падает.
- Секреты (пароли, ключи, токены) не хранятся в localStorage: `src/core/secrets.ts`
  кладёт их в системное хранилище через команды Rust, в профиле базы остаются
  только открытые поля.
- Ссылка на файл для показа в WebView берётся из `src/core/fs/assets.ts`
  (`convertFileSrc` в приложении, blob-URL в браузере).
- Живой WebDAV для проверки синхронизации: см. README, раздел про живой сервер.
- Любое действие, доступное по правому клику или наведению, дублируется кнопкой «…»
  и работает одним тапом — иначе на телефоне до него не добраться.

## Проверка перед коммитом

```bash
npm run typecheck && npm test && npm run build
cd src-tauri && cargo check
```
