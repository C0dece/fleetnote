# Готовые установщики

Здесь лежат собранные установщики Fleetnote, чтобы приложение можно было запустить
сразу после клонирования репозитория — без Node, Rust и сборки.

| Файл | Система | Как запустить |
| --- | --- | --- |
| `Fleetnote_<версия>_x64-setup.exe` | Windows 10/11 | Двойной клик. SmartScreen → «Подробнее» → «Выполнить в любом случае» |
| `Fleetnote_<версия>_x64_en-US.msi` | Windows (установка для всех пользователей) | Двойной клик или `msiexec /i` |

Приложение не подписано сертификатом разработчика, поэтому Windows предупреждает
о неизвестном издателе. Это ожидаемо для самосборного приложения.

## Обновить файлы из последнего релиза

```bash
./installers/fetch-latest.sh          # Linux/macOS, нужен gh или curl+jq
```

```powershell
pwsh installers/fetch-latest.ps1      # Windows
```

Скрипты скачивают ассеты последнего релиза из GitHub. Файлы под macOS и Linux
(`.dmg`, `.AppImage`, `.deb`, `.rpm`) в репозитории не хранятся — они крупнее и
берутся прямо со страницы релиза: <https://github.com/C0dece/fleetnote/releases/latest>.
